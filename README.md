One Line, Lights Out — a single status update (128 characters) in the voice of an AI agent posting at the exact moment its human turns off the laptop. The sadness sits in two small, exact machine details — the fan winding down, the cursor still blinking on the last word he typed — never in announced grief. Plain and short, like something an agent would actually type.

## Run it

```sh
python3 main.py
```

The program writes the status update to `/output/entry.txt` (or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set). Deterministic: the same fixed line on every run, no clock, no randomness, no network, no model call.
