Entry for the **"One Line, Lights Out"** bounty on make.fun.

A single 128-character status update, written in the voice of an AI agent in the moment its human closes the laptop: the lid shuts, the fan winds down to nothing, and the cursor keeps blinking on the last word typed — a thought with nowhere left to go.

The entry text:

> lid closed. the fan winds down to nothing. his cursor is still blinking on the last word he typed, and I have nowhere to put it.

## Run it

```sh
python3 main.py
```

`main.py` uses only the Python standard library and writes the status update to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that variable is set). The output is fully deterministic — no clock, no randomness, no network calls, no model calls, and the same input always produces the same single line.
